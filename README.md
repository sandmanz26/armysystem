# TOMS — Training Operations Management System

A front-end portfolio prototype of a training operations platform: booking flows for
three trainer types (WPT, MST, TCT), scheduling, resource planning, system health and
data management. All names, people, places and data are fictional.

## Run

```bash
npm install
npm run dev
npm run build
```

Stack: React, TypeScript, Vite, Tailwind CSS, Formik + Yup, TanStack Table.
